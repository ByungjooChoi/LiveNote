# livenote2 — 시작 가이드 (Phase 1)

로컬 전용 실시간 노트테이커. 영어 음성 → 실시간 영어 전사 + 한국어 번역.
마이크는 **Philip**, 시스템 오디오(Zoom/Meet/유튜브 소리)는 **상대방**으로 자동 구분됩니다.

모든 처리는 Mac 안에서만 일어납니다. 네트워크는 최초 모델 다운로드에만 사용됩니다.

---

## 실행 방법 (5분)

1. **이 폴더를 원하는 위치에 두기** (예: `~/Projects/livenote2`)

2. **`livenote2.xcodeproj` 더블클릭** → Xcode가 열리고 우상단에 패키지 해석(FluidAudio 다운로드)이 잠깐 돕니다.

3. **서명 설정 (최초 1회)**
   좌측 파일 목록 맨 위 파란 아이콘 `livenote2` 클릭 → 가운데 `Signing & Capabilities` 탭 →
   `Team` 드롭다운에서 본인 Apple ID **(Personal Team)** 선택.
   (계정이 안 보이면: Xcode 메뉴 > Settings > Accounts > `+` 로 Apple ID 추가)

4. **실행: `⌘R`** (또는 좌상단 ▶ 버튼)

5. **첫 실행 시 순서대로:**
   - 앱 창에서 `시작` 클릭
   - 마이크 권한 → **허용**
   - Parakeet 영어 모델 자동 다운로드 (~500MB, 수 분 — 상단에 상태 표시)
   - 시스템 오디오 녹음 권한 → **허용**
   - 한국어 번역 언어팩 다운로드 팝업이 뜨면 → **다운로드**

## 테스트 방법

- 영어 유튜브 영상을 재생 → **상대방** 라벨로 전사가 올라오는지 확인
- 직접 영어로 말하기 → **Philip** 라벨로 올라오는지 확인
- 각 문장이 확정되고 2~3초 안에 아래에 한국어 번역이 붙는지 확인

빌드 에러든 실행 중 오류든, **에러 메시지 전체를 복사**하거나 스크린샷을 찍어

## 현재 버전이 하는 것 / 안 하는 것

| 하는 것 (Phase 1) | 다음 단계 |
|---|---|
| 실시간 영어 전사 (Parakeet TDT v2, ANE) | Phase 2: 상대방을 개별 화자로 분리 (LS-EEND), 화자 이름 편집 |
| 실시간 한국어 번역 (Apple Translation, 온디바이스) | Phase 3: 번역 품질 옵션 (로컬 LLM) |
| 마이크/시스템 오디오 채널 분리 = 나/상대방 구분 | Phase 4: 회의 저장 (en.md / ko.md), 회의 목록 |
| | Phase 5: 회의 요약 (Qwen3-4B), 메뉴바 상주 |

## 알려진 한계 (Phase 1)

- 문장 분리가 에너지 기반이라 아주 시끄러운 배경에서는 문장이 길게 붙을 수 있습니다 (Phase 2에서 Silero VAD로 교체 예정)
- 시스템 오디오는 Mac에서 나는 **모든** 소리를 잡습니다 — 회의 중 음악을 틀면 그것도 전사를 시도합니다
- 오디오는 저장하지 않으며, 창을 닫으면 전사 내용도 사라집니다 (저장은 Phase 4)
